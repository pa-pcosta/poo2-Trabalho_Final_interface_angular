# Como rodar

**1 - Rodar o backend** 

- Abra um novo terminal e navegue para o diretório *backend/*  
```cd backend/```

- Execute o programa  
  ```mvn spring-boot:run```

**2 - Rodar o frontend**  

- Abra um novo terminal e navegue para o diretório *frontend/*  
```cd frontend/```

- Instale as dependências  
  ```npm install```  
  
- Rode o frontend e acesse o endereço fornecido  
  ```ng serve```
